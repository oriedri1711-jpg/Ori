# Between Us – המשחק שמקרב בינינו

אפליקציה זוגית שעובדת בלי חשבון ובלי שרת: כל המידע נשמר על הטלפונים, והטלפונים מתחברים ישירות זה לזה.

## התקנה
- **אנדרואיד:** מורידים את `BetweenUs.apk` מעמוד ה-Releases (גרסה "latest"), פותחים, ומאשרים "התקנה ממקור לא ידוע".
- **אייפון:** פותחים את קישור האתר (GitHub Pages) ב-Safari ← כפתור השיתוף ← "הוספה למסך הבית".
- **אנדרואיד בלי APK:** פותחים את הקישור ב-Chrome ← תפריט ← "התקנת אפליקציה".

## איך משחקים ביחד
שניכם מזינים את אותו שם חדר ואותה סיסמה, כל אחד בטלפון שלו. כששתי האפליקציות פתוחות באותו זמן, הטלפונים מתחברים (גם מרחוק), ורואים מי מחובר, משחקים על אותו קלף ומסנכרנים תשובות. כל 5 שניות האפליקציה מרעננת ושולחת את המצב מחדש.

- החיבור נעשה דרך WebRTC. השרת הציבורי החינמי של PeerJS משמש רק כדי שהטלפונים ימצאו זה את זה; התוכן עובר ישירות ביניהם.
- אין שמירה בענן: מה שלא סונכרן כששניכם מחוברים נשאר בטלפון שבו נכתב.
- משחק על טלפון אחד עובד תמיד, גם בלי אינטרנט.

## למפתחים
- `src/` – קוד המקור המשותף (אותו קוד שרץ גם כ-Claude artifact). `p2p.js` מחליף את שכבת החיבור של Claude בחיבור ישיר.
- `python3 build.py ./node_modules` בונה את `www/` (גופנים מקומיים, manifest, service worker לעבודה בלי אינטרנט).
- כל push ל-main מריץ את `.github/workflows/build.yml`: בונה APK עם Capacitor ומפרסם ל-Releases, ומעלה את `www/` ל-GitHub Pages.
- `keystore/debug.keystore` הוא מפתח debug קבוע (סיסמה android), כדי שעדכונים יותקנו מעל הגרסה הקודמת.
